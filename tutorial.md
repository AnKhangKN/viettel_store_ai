# Hướng dẫn Vận hành & Chuyển đổi Môi trường (Viettel Store AI Tutorial)

Tất cả các tài liệu hướng dẫn vận hành, kiểm thử (Deployment Test) và chuyển đổi dự án sang Môi trường Production đã được tổng hợp đầy đủ trong thư mục [**tutorial/**](./tutorial/).

---

## 📂 Danh mục Hướng dẫn trong thư mục `tutorial/`

1. 📝 [**tutorial/TASKS.md**](./tutorial/TASKS.md): **[DANH SÁCH TASK]** Chi tiết các task phát triển tiếp theo (Xác thực Email OTP, Responsive Mobile, Giao diện Login, Validate Profile) và các đề xuất nâng cấp.
2. 📖 [**tutorial/README.md**](./tutorial/README.md): Tổng quan hướng dẫn và cách khởi chạy nhanh hệ thống.
3. 🔄 [**tutorial/TUTORIAL_SWITCH_ENV.md**](./tutorial/TUTORIAL_SWITCH_ENV.md): **[QUAN TRỌNG]** Hướng dẫn chi tiết chuyển đổi giữa môi trường **Deployment Test** và **Production** (Các file đã chỉnh sửa & quy trình trả lại trạng thái Production).
4. 🧪 [**tutorial/TUTORIAL_LOCAL_TESTING.md**](./tutorial/TUTORIAL_LOCAL_TESTING.md): Hướng dẫn khởi chạy, thiết lập PostgreSQL Docker và kiểm thử từng tính năng (Chatbot AI, Đặt số thứ tự WebSocket, Thanh toán VNPay, Tra cứu CSKH Excel).
5. 🚀 [**tutorial/TUTORIAL_PRODUCTION_DEPLOY.md**](./tutorial/TUTORIAL_PRODUCTION_DEPLOY.md): Hướng dẫn từng bước triển khai Backend (Render), Frontend (Vercel) và Cloud PostgreSQL Database.
